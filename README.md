# 家庭头像小游戏

这是一个轻量的网页版 9 x 9 家庭头像小游戏，包含两个玩法：

- 消消乐模式：交换相邻头像，横向或纵向 3 个及以上即可消除。
- 连连看模式：点击两个相同头像，路径最多 2 次转弯即可消除。

两个玩法共用同一套家庭头像素材、棋盘渲染、音效开关和页面风格。人物头像使用参考图裁切成的本地素材，不依赖外部图片资源。

## 如何运行

不需要安装依赖，也不需要联网。

直接用浏览器打开 `index.html` 即可开始游戏。

如果想通过本地服务运行，也可以在本目录执行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 玩法说明

### 消消乐

- 棋盘大小为 9 x 9。
- 点击一个头像，再点击上下左右相邻的另一个头像进行交换。
- 也可以按住头像后向上、下、左、右滑动，和对应方向的相邻头像交换。
- 如果交换后形成横向或纵向 3 个及以上相同头像，交换成功并消除。
- 如果没有形成消除，会自动换回原位置。
- 消除后上方头像会下落，顶部自动补充新头像。
- 补齐后如果再次形成组合，会继续自动连锁消除。
- 初始步数为 30 步。
- 只有有效交换会消耗 1 步。
- 步数为 0 时游戏结束，并显示最终得分。

### 连连看

- 棋盘大小为 9 x 9。
- 使用同一套家庭头像资源。
- 棋盘中有 80 张成对头像和 1 个空格。
- 点击两个相同头像，如果路径可连接则消除。
- 支持直线、L 型和最多 2 次转弯的路径。
- 路径不能穿过其他头像。
- 允许从棋盘外圈绕路。
- 每对 +10 分。
- 初始步数为 60 步。
- 每成功消除一对头像消耗 1 步，点错不消耗步数。
- 步数用完则游戏结束，清空所有头像即通关。

## 得分规则

- 消除 3 个：+30 分
- 消除 4 个：+60 分
- 消除 5 个及以上：+100 分
- 连锁消除会获得倍率：第二轮 x1.2，第三轮及以后 x1.5

## 已实现功能

- 9 x 9 棋盘
- 8 种家庭成员本地头像素材
- 初始棋盘避免直接出现可消除组合
- 相邻交换判断
- 无效交换自动换回
- 横向和纵向消除检测
- 一次消除多个组合
- 下落补齐
- 连锁消除
- 分数与步数显示
- 游戏结束弹窗
- 重新开始
- 鼠标悬停、选中、交换、消除、下落、新头像生成动画
- 消除音效，可在页面顶部开关
- 点击交换和上下左右滑动交换
- 消消乐 / 连连看模式切换
- 连连看路径判断，支持外圈通路和最多 2 次转弯
- 统一头像资源和统一棋盘渲染
- 移动端自适应布局

## 部署说明

推荐直接部署完整项目结构，而不是把 CSS、JS、图片重新打包进单个 HTML。

GitHub Pages 使用 `main` 分支根目录时，需要上传：

- `index.html`
- `style.css`
- `game.js`
- `avatar.js`
- `board.js`
- `match3.js`
- `linkGame.js`
- `utils.js`
- `assets/`
- `.nojekyll`

后续如果只改按钮样式，通常只需要更新 `style.css`；如果只改某个玩法，通常只需要更新对应的玩法文件。
